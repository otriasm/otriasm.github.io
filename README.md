# otriasm.github.io

Sitio personal de Oscar Trías — Senior Product Manager · Product Builder.

## Estructura

| Ruta | Qué es |
|---|---|
| `index.html` | Sitio en español (Versión B · violeta y fucsia). Es lo que publica GitHub Pages. |
| `en/index.html` | Versión en inglés (aún con el diseño A; pendiente de traducir la Versión B). |
| `assets/` | Logos de certificaciones (Colectivo 23, Ironhack). |
| `cv/` | `OscarTrias_CV.pdf`, el archivo de los botones "Descargar CV". |
| `design/` | Respaldo de las fuentes del diseño (archivos `.dc.html` del canvas de Claude Design y `canvas.json`). No se publican como páginas. |

## Publicación

GitHub Pages sirve la rama `main` desde la raíz: Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
